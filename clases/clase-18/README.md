# Clase 18 - Trabajo colaborativo con Git

## Temas de la clase

- Repositorio remoto y copia local.
- Flujo compartido sobre `main`: `pull`, trabajo local, `add`, `commit`, `pull`, `push`.
- Commits propios de cada integrante.
- Coordinacion de archivos y partes del TP Integrador.
- Rechazo de `push` por cambios remotos.
- Conflictos de merge a nivel introductorio.

## Estructura de la clase

- `material/`: presentacion usada en clase.

## Material

- [Clase 18.0 - Trabajo colaborativo con Git](./material/clase-18.md)

## Para practicar

1. Hacer commits propios en archivos separados.
2. Sincronizar antes de subir cambios.
3. Provocar y resolver un conflicto simple en un archivo compartido.
