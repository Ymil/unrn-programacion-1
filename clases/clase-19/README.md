# Clase 19 - Fechas y horas con `datetime`

## Temas de la clase

- Fechas recibidas como texto desde `input()` o archivos.
- Creacion y consulta basica de objetos `datetime`.
- Conversion de texto a fecha con `strptime()`.
- Formatos personalizados y codigos como `%d`, `%m`, `%Y`, `%H`, `%M` y `%S`.
- Validacion de fechas con `ValueError`.
- Conversion de fecha a texto con `strftime()`.
- Comparacion de fechas y operaciones simples con `timedelta`.
