# Clase 16 - JSON en Python

## Temas de la clase

- JSON como formato de almacenamiento e intercambio de datos.
- Lectura de archivos `.json` y reconocimiento de su sintaxis.
- Escritura de datos con `json.dump()` y uso de `indent`.
- Lectura de datos con `json.load()`.
