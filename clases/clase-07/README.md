## Temas de la clase

- Repaso de funciones, parametros y valores de retorno.

- Recorrido de listas usando indices con `range`.

- Busqueda de maximos y conteo de repeticiones sin usar `max` ni `count`.
- Conteo de numeros positivos y negativos.
